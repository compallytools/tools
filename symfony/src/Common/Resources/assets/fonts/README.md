# Fonts

Polices de la charte de <https://chloecorfmat.fr/> (fichiers récupérés sur le site, droits confirmés).
Déclarées dans `../styles/_fonts.scss`.

| Fichier | Police | Usage |
|---|---|---|
| `MomentzCorfmat-Regular.woff2` | Momentz Corfmat | Titres h1, h2 |
| `Fredoka-VariableFont.woff2` | Fredoka (variable, 300 à 700) | Texte courant, h3, boutons, formulaires |
| `KanopiBrazilCorfmat-Regular.woff2` | Kanopi Brazil Corfmat | Décoratif uniquement |
